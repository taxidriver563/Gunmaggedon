F-88 / F-120 secondary ground AP capability
2026-10-25 | runtime1.20.0 installed | existing pack0.0.38 | network protocol8

Scope and behavior
Regular F88 and F120 now engage visible hostile GroundVehicles and Buildings
with direct-fire AP when no active eligible aerial engagement takes priority.
Ships and parked low-altitude aircraft do not become ground targets. F120S keeps
its special incendiary loadout; GroundEnabled explicitly excludes it.
New behavior is automatic and uses each gun's existing ammunition reserve,
single-round loading, breech/casing/recoil sequence and native station. There is
no extra magazine, free ammunition or user configuration. No new unit/prefab.

Native muzzle velocity, mass, gravity and quadratic drag are retained. Penetration
values are native pierceDamage inputs, not direct HP damage. Armor/geometry and
flight-speed-squared loss still determine the result; no guaranteed tank kill.

Selection and evidence
Uses the existing half-second SharedWorldQueries candidate snapshot. Broad grid
membership never supplies detection evidence. Ground targets require exact
range, same existing hostile-HQ checks, active/non-disabled state, own native
LOS and smoke checks. Night/low-light uses the existing clock gate and requires
existing flare illumination; these guns do not launch new flares themselves.
Ground aim height uses45percent of definition height (minimum1m). Motion lead
comes from observed global-coordinate positions, not target Rigidbody velocity.
Requires multiple samples over at least.35sec; motion capped120m/s and expires
at1sec without new observations. Prediction includes observation age and actual
shell flight using the existing gravity/drag trajectory solver. Minimum3aim
iterations and native alignment/readiness still gate fire. Pose/traverse rates
remain identical to the corresponding AA profile; elevation stays -5..85deg.

Eligible detected aircraft, and supported F120 Piledrivers, preempt ground fire.
Existing valid lost-contact AA continuation is retained before ground fallback.
Dead/invalid old targets no longer block selection until their stale track ages
out. Friendlies in the same HQ cannot be selected; this is not a guarantee that
a friendly moving into the physical projectile path can never be struck.
Ground shots require stationary operational trailer and server authority; they
stop on lost immediate optical evidence rather than firing at an unseen memory.

Native ammunition/damage and lifecycle
F88GroundFire.cs is a partial of the existing F88 controller; FlakGroundPolicy
provides range/dispersion and sampled velocity. F88FlakRuntime.AllowFire latches
APQueued at accepted native Fire, before native SpawnBullet. Later air selection
cannot turn an already queued/launched AP round into flak. Each authoritative
AP round owns a WeaponInfo clone with zero blast/airburst fields and calibrated
penetration. The original shared flak profile is never mutated. Native tracing
uses this profile by reference, clears explosive/proximity state, and handles
collision, armor and speed loss. Native Fire/SpawnBullet and actual UnitPart
penetration/HP damage were exercised independently of muzzle effects.
AP expiry never calls BlastFrag, F88Fragments or incendiary carrier logic.
Ricocheting active rounds retain their profile. Retirement, failed/unbound
launch, exceptions, mission reset and shutdown release cloned profiles and
references. Launched authority is retained if the source disappears; authority
handoff to a nonserver suppresses damage. The destruction case validates trace
profile/visualOnly routing, not a separate full mission posthumous-kill test.
OptimizationRuntime.Clear now clears F88 native flight ownership too.

Impact presentation
Reuses the compact AP spark helper/stock impact audio and preserves water slot2.
Native Bullet.Trace calls its effect slots directly, so ground AP supplies a
single harmless no-render/no-audio native PrefabEffect wrapper for suppressed
HE slots instead of null references. The wrapper has no particles/lights/model
renderers and is destroyed on mission reset. Land/armor gets a compact one-shot
spark; there is no extra damaging cloud. Existing traveling audio handles delay.
The older coastal AP effect-slot code is not changed by this feature pass.
New FlakAPImpact message carries global position, velocity, source and server
clock. Client presentation validates finite values, known valid source when
present and age -1..3sec. Missing destroyed source can still show sparks without
borrowed source audio. Message has no damage path. Handshake7->8 excludes older
runtimes from custom presentation to prevent unknown-message handling. Matching
runtime1.20.0 peers required. Native codec tested; live MP transport not certified.
Native remote bullet visuals still originate from the base gun; exact client
impact mixing/deduplication under network latency remains a mission check.
