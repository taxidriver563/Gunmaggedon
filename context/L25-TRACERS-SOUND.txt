L25 tracer cadence and custom firing sound - Runtime 1.9.6 / pack 0.0.25

Final user preference: one tracer every THREE actual shots across the mount.
The intermediate one-in-five request was changed before installation.

Native Gun.Awake randomizes a tracer seed separately for each feed. L25 now
uses one successful-shot phase on the mount, preparing the selected gun's
native seed immediately before SpawnBullet. Native code increments the seed
then checks seed > tracerRatio, so phase two prepares seed three and the
other phases prepare zero. All six rig/operational feed assets use ratio three.
Successful shots advance the phase; skipped or failed spawns do not. Reloads
and temporarily unavailable feeds do not reset the phase. Tracer emission is
strictly on total shots 3, 6, 9, etc., not one counter per barrel. During a
perfect left/middle/right cycle, this means the right barrel emits the tracers;
skipping a feed can change which physical barrel fires the next tracer.
Each remote instance follows its received shot events; no new late-join phase
synchronization protocol is introduced.

All three guns on both prefabs now use 25mm_Autocannon_Fire.mp3 as their native
one-shot firing sound. The clip decodes non-silent audio, duration 3.048s.
One AudioSource per feed and no looping rotary start/sustain/end layers.
Base pitch is one with small 0.025 pitch variation; the old stock rotary 0.8
pitch setting is removed. Original audio file is retained without trimming.
