Runtime **1.10.0** + asset pack **0.0.26**. Both are required.

### Added

- **F88 heavy flak trailer:** predicted-area barrages, timed airbursts, custom firing/explosion audio, lingering flak puffs, and a full loading sequence with extraction, casing ejection, a two-second clearance pause, insertion, and a secured breech.
- **L25 triple AA trailer:** 3.5 km close-defense range, staggered firing, independent 15-round clips, custom 25 mm sound, and one tracer every three shots across the battery.
- Three model LOD levels for every unit, with unnecessary distant animations suppressed while targeting, firing, damage, and reload clocks keep running.

### Changed and fixed

- F88 fragments now cover a broader 140 m envelope with distance falloff and armor/obstruction checks. Repeated bursts can wear aircraft down without making the whole radius an instant kill.
- Searchlights lock onto visible aircraft more smoothly and use rough engine-noise estimates within 3–5 km. Radar support remains more precise.
- Coastal batteries within 2 km can request searchlight support against ships. Aircraft remain the priority. Improved distant naval tracking, inclined-trailer aiming, and request persistence.
- Searchlight beams use a soft cloud cutoff that fully removes the beam beyond the cloud boundary. Ranging trails are brighter and last four seconds.
- Fixed special-payload replication, dense slug-collision queries, smoke blocking searchlights, and failed top-attack reservation cleanup.
- Runtime optimization pass: pooled effects, trails and travelling audio; bulk trail uploads; shared detection/radar queries and ship bounds; less cleanup allocation; consolidated F88 presentation updates. Active effects are not capped to achieve these savings.

### Installation

Download **Gunmaggedon.Runtime.zip** and **Gunmageddon_0.0.26.nobp**. Extract the ZIP into the game folder and put the asset pack in `BepInEx/plugins`. Remove old runtime copies and older active packs. Existing configuration is retained. The ZIP contains the runtime only.

The release workflow builds and attests the runtime from this tag. The asset pack is built separately with Unity/Blueprinter.

### Alpha notes

- All 14 standalone suites passed locally, plus 1,568 checks across ten Unity groups. The staged L25 preview rig has a known tracer-setting mismatch; the live trailer passes its checks and uses the intended ratio.
- Editor trail-churn benchmarks improved, but full combat FPS, native GC allocations, and live multiplayer behavior remain unverified.
- Custom mission hitch/unhitch remains disabled. Remote searchlight pointing still uses local sweeps.
