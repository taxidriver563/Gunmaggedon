# Alpha v0.0.34 - heavy flak and Stratopenetrators

Requires **runtime 1.14.2 + asset pack 0.0.34**. Replace older runtime/pack copies rather than leaving both active. This is a prerelease candidate; no release has been published yet.

- Added F-120 heavy flak with improved fire-control estimates, tighter suppression, a larger fragmentation envelope, and an upward-sliding breech. Fixed its damage routing.
- Added R-230 long-range railgun defense, with a 5 km minimum and 65 km maximum range, threat-based targeting, terminal Piledriver priority, capacitor cycles, and a visible pre-fire warning.
- Added R-230N with the stock 1.5 kt nuclear airburst effect, swept proximity checks, and a larger danger indicator. Corrected nuclear-effect selection to exclude UFO effects.
- Tuned warning beams to native laser emission with a small boost. Removed R-230 recoil and corrected effect initialization/cleanup.
- Strengthened CD-203 concrete resistance and standardized unit designations.
- Preserved the denser L-25 tracer setting, applied it to the spawnable trailer, and removed the runtime override that forced every-third-shot tracers.
- Corrected validation assembly loading so sequential suites use consistent Unity component types. CI packaging now reads the compatible pack version from modinfo.json.

## Validation and limits

All 19 current Unity validation groups pass in isolated preview scenes. All 16 standalone suites passed locally: 15 under Unity Mono and the optimization suite under the installed .NET 6 runtime. The exact pinned .NET 10 hosted CI workflow and provenance are still pending. Native effects are borrowed from the installed game; original game DLLs and native art/audio are not included in this update.

Live mission verification of the 1.5 kt blast, final visual balance and multiplayer transport is still pending. Editor fixtures do not certify those results. The revamped carriage remains a staged development rig.
